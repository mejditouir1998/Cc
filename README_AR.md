# موقع تسجيل الدخول العربي — جاهز للنشر على Render

## خطوات النشر
1. أنشئ حساباً في Render ومستودعاً خاصاً في GitHub.
2. ارفع محتويات هذا المجلد إلى المستودع. لا ترفع كلمات المرور أو ملف `.env`.
3. في Render اختر **New +** ثم **Blueprint** واربط مستودع GitHub.
4. سيقرأ Render ملف `render.yaml` وينشئ خدمة الويب وقرصاً دائماً لقاعدة البيانات.
5. أدخل `ADMIN_EMAIL` و`ADMIN_PASSWORD` في إعدادات Render عند الطلب. استخدم كلمة مرور طويلة وفريدة.
6. بعد اكتمال النشر ستحصل على رابط HTTPS؛ افتحه لاختبار التسجيل والدخول ولوحة المدير.

## تشغيل محلياً
```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```
اضبط `SECRET_KEY` و`ADMIN_EMAIL` و`ADMIN_PASSWORD` كمتغيرات بيئة، ثم شغّل `python app.py`.
افتح `http://127.0.0.1:5000`.

## الأمان
- لم يتم نشر الموقع تلقائياً؛ يلزم ربط حساباتك واتباع الخطوات أعلاه.
- لا ترسل كلمة مرور الاستضافة أو المدير أو `SECRET_KEY` في المحادثة.
- القرص الدائم مفعّل لحفظ قاعدة SQLite.
- قبل الإطلاق العام، أضف تحديد معدل محاولات الدخول، واستعادة كلمة المرور، والتحقق من البريد، ومراجعة أمنية.
